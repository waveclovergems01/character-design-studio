# Character Design Studio

เครื่องมือเปิดรูปตัวละคร + Markdown Character Map เพื่อ **เลือกชิ้นส่วนบนภาพ ตรวจสี/เทคนิค และสร้างคำสั่ง AI แก้เฉพาะส่วน** สำหรับงานวาดตัวละคร 2.5D ของ My-Game-Design

โปรเจกต์นี้เป็น Local-first MVP ใช้ **React 19 + TypeScript + Vite 8 + Tailwind CSS 4 + PixiJS 8** ไม่มี backend, database, API key หรือค่า AI ประจำเดือน

## ใหม่ v0.12 — นำเข้าเพิ่ม / ลบ / สลับ / ลากแทรกเฟรมใน Animation Preview

- เปลี่ยนจากการนำเข้าแล้วเขียนทับทุกครั้ง เป็น **Timeline เดียวที่รวม PNG/JPEG/WebP หลายรอบและ Sprite Sheet หลายแผ่นได้** จะสลับแท็บชนิดไฟล์เพื่อนำเข้าคนละแบบก็ยังเก็บรูปชุดเดิม
- แยกปุ่ม **เพิ่มรูปเข้าชุดปัจจุบัน** ออกจาก **นำเข้าชุดใหม่ (แทนที่ทั้งหมด)** อย่างชัดเจน ทั้งโหมดหลายรูปและ Sprite Sheet; เมื่อต้องแทนที่ทั้งหมด ระบบถามยืนยันก่อนเปิดไฟล์
- **ลบเป็นรายเฟรม:** ปุ่ม × บนการ์ด (แสดงเมื่อชี้เมาส์) หรือเลือกการ์ดแล้วกด **ลบเฟรมที่เลือก**; การ์ดหลังจากนั้นเลื่อนเข้ามาแทน และจำนวนเฟรมปรับตามจริง
- **ลากสลับและแทรก:** จับการ์ดใน Frame Strip ลากไปทางซ้ายหรือขวาของการ์ดเป้าหมาย เส้นสีเขียวแสดงตำแหน่ง *แทรกก่อน/หลัง*; ยังมีปุ่มสลับซ้าย/ขวาไว้สำหรับคนไม่สะดวกลาก
- **ล้างทุกเฟรม** พร้อมยืนยันก่อนล้าง; ภาพที่นำเข้าถูกล้างออกจาก Timeline ส่วนเครื่องมือ Rig / Bone / Mask / Weight ไม่ได้รับผลกระทบ
- การเพิ่ม Sprite Sheet ตั้ง **จำนวนช่องที่จะนำเข้ารอบนี้** ได้อิสระจากจำนวนแถว/คอลัมน์ เช่น 4 คอลัมน์ × 2 แถว แต่ใช้เพียง 6 เฟรม; การเปลี่ยนกริดภายหลังไม่ตัดภาพที่นำเข้าแล้วซ้ำ

หมายเหตุ: ทุกอย่างทำงานในหน่วยความจำของแท็บเบราว์เซอร์เท่านั้น (ไม่บันทึกเมื่อรีโหลด); รองรับสูงสุด 256 เฟรม และยังเป็น **Preview** ไม่แก้ไขไฟล์ต้นฉบับ ดูขั้นตอนใน `UPDATE_v0.12.0.md`

- **โหมด Sprite Sheet:** เลือกภาพแผ่นเดียว กำหนดจำนวน **คอลัมน์ (แนวนอน) และแถว (แนวตั้ง)**; แยกช่องเท่า ๆ กันตามขนาดภาพจริงจากซ้ายไปขวา บนลงล่าง และตั้ง **จำนวนเฟรมจริง** น้อยกว่าจำนวนช่องได้ เช่น แผ่น 4×2 มี 8 ช่อง แต่ใช้ 6 เฟรม

- มี Timeline แนวนอนพร้อมภาพย่อ, Checkerboard, Onion Skin ของเฟรมก่อน, Guide แนวกลางและแนวเท้า, จัดภาพล่างกึ่งกลาง/กึ่งกลาง และขยายพรีวิว 25–250%; เหมาะดูว่าตัวละครกระโดด เปลี่ยนขนาด หรือรอยต่อในแต่ละเฟรมผิดตรงไหน
- กำหนดเฟรมใช้งานได้ **1–256 เฟรม** ต่อชุด, สลับไปโหมดอื่นใน Workspace แล้วกลับมาได้โดยไม่ต้องนำเข้าภาพใหม่ตราบใดที่ยังอยู่ในหน้า Workspace เดียวกัน

**ข้อจำกัด:** โหมดนี้เป็น **Preview เท่านั้น** ไม่แก้ไขไฟล์ภาพ ไม่เชื่อมกับ Bone/Weight ไม่ส่งรูปออกเป็นไฟล์ใหม่ และไม่เก็บภาพข้ามการรีโหลดหน้าเว็บ ภาพ Sprite Sheet ควรมีช่องเฟรมขนาดเท่ากัน; หากมี GIF ให้แปลงเป็น PNG Frames หรือ Sprite Sheet ก่อน รายละเอียดใน `UPDATE_v0.11.0.md`

## ใหม่ v0.10 — Bone Edit + Weight Paint + Auto Weight

- **Rig & Motion** มีเครื่องมือแยก 4 แท็บที่ติดอยู่ใต้แถบเลือกเฟรม: **Bone / Mask / Weight / Depth** ทำให้การปรับกระดูก ขอบภาพ น้ำหนัก Mesh และลำดับการซ้อนภาพไม่ปนกัน
- **Bone:** ต้องเข้าแท็บ Bone แล้วเปิด **Edit Bones** ก่อนลากข้อ จึงลดการเผลอขยับโบนในโหมดอื่น; เปิด/ปิดเส้นโบนได้ และมี **Mirror ข้อต่อ** เพื่อสะท้อนตำแหน่งคู่ซ้าย–ขวาบนแนวแกนกลางตัวละคร (ใช้เมื่อมุมภาพสมมาตร)
- **Weight:** เลือกชิ้นส่วนที่ต้องเพ้นต์และกระดูกหลัก/กระดูกข้างเคียง จากนั้นเปิด **Edit / Paint** แล้วลากเมาส์บนภาพ; มี Heatmap น้ำเงิน 0% → แดง 100%, แปรง **เพิ่ม / ลบ / กำหนด / เกลี่ย**, Brush Size, Strength และน้ำหนักเป้าหมาย
- **Auto Weight:** สร้างน้ำหนักเริ่มต้นแบบนุ่มบริเวณรอยต่อบนตาราง **11×15 จุดต่อชิ้นส่วน**; จำกัดอิทธิพลไว้ที่กระดูกหลักกับกระดูกข้างเคียง **ฝั่งเดียวกันตามกายวิภาค** เพื่อป้องกันอาการกระดูกแขนไปติดขาตรงจุดใกล้กันบนภาพ ไม่มีการวิเคราะห์อวัยวะด้วย AI
- **PixiJS Cutout Preview:** คำนวณตำแหน่ง Vertex จากน้ำหนักกระดูกทั้งสองส่วนแบบ normalized (รวม 100%) จึงผสมการดัดบริเวณรอยต่อได้; ส่งออกค่าน้ำหนักต่อ Vertex ใน Motion JSON และ `data/cutout_layers.json` ของ Cutout ZIP

**ข้อจำกัด:** นี่เป็น **2-bone skinning prototype** (สองอิทธิพลต่อชิ้นส่วน) ไม่ใช่ระบบ Weight Paint ของ Spine/Blender เต็มรูปแบบ น้ำหนักกำหนดลง Mesh ของชิ้นส่วน ไม่ได้รู้รูปทรงมนุษย์จากสีภาพจริง หากแก้ Polygon หรือ Bone ต้นทางควรสร้าง Auto Weight ใหม่และเกลี่ยอีกครั้ง และภาพ PNG แบนหนึ่งภาพยังไม่มีรายละเอียดใต้บริเวณที่ถูกบัง จึงอาจมีช่องว่างที่ต้องวาด **Underlay/Backfill** เพิ่มด้วยมือ ดู `UPDATE_v0.10.0.md`

## ใหม่ v0.9 — คลิกขวาบน Canvas + Rig UI แบบกระชับ

- ใน **Rig & Motion** เลือก Mask ใดก็ได้ แล้ว **คลิกขวาบนภาพ** เพื่อเปิดเมนูที่ตำแหน่งเมาส์: เพิ่มจุดที่ขอบใกล้สุด, เลือก/ลบจุดใกล้เมาส์, แปลง Capsule เป็น Polygon 16 จุด, วาด Polygon ใหม่, คืนขอบ และปรับหน้า/หลังลำตัวในเฟรมปัจจุบัน
- ปุ่ม **เพิ่มจุด** แปลง Capsule เป็น Polygon ให้อัตโนมัติเมื่อต้องการ และใช้ระยะจริงของ Canvas ในการเลือกจุดใกล้เมาส์ (ภายใน 26 px) จึงใช้งานได้ที่หลายระดับ Zoom · กด Escape หรือคลิกนอกเมนูเพื่อปิด
- ส่วนเลือกทิศ/Motion/จำนวนเฟรม, ปุ่มเลื่อนเฟรม และแท็บ Mask / Depth จะ **ค้างอยู่ด้านบนของ Inspector** ระหว่างเลื่อน; การสร้างเฟรม/คัดลอกเฟรม, ตัวเลือก Capsule ขั้นสูง และเครื่องมือ 19 ข้อต่อเก็บเป็นหัวข้อพับได้เพื่อลดการเลื่อนขึ้นลง
- มีคำอธิบายช่องว่างใต้แขนจากภาพแบนและแนวทางทำ **Backfill/Underlay ใน Krita** แต่เวอร์ชันนี้ **ยังไม่รองรับการนำเข้า Underlay แบบ Layer แยก** และไม่ได้เติมรายละเอียดที่ถูกบังให้เอง ดูรายละเอียด `UPDATE_v0.9.0.md`

## ใหม่ v0.8 — Pen Tool Polygon Cutout + Layer Order รายเฟรม

- ใน Rig & Motion เลือกแท็บย่อย **ตัดภาพ / Polygon** แล้วเลือกชิ้นส่วน เช่น มือซ้าย ต้นแขน หรือรองเท้าขวา
- กด **เริ่มแก้ขอบแบบ Pen Tool** เพื่อเปลี่ยน Capsule Mask เป็น Polygon เริ่มต้น 16 จุด แล้วลากจุดขอบสีเขียวให้ตรงขอบภาพจริง จะกด **เพิ่มจุดบนขอบ** เพื่อแทรกจุดบนเส้นที่ใกล้สุด หรือกดเลือกจุดและ **ลบจุดที่เลือก** ก็ได้
- หากไม่ต้องการทรงเดิม กด **วาด Polygon ใหม่จากศูนย์** คลิกทีละจุดบนรูปอย่างน้อย 3 จุด แล้วกด **จบ Polygon** มีปุ่มย้อนจุดล่าสุด/ยกเลิก; การแก้ไข Polygon จะส่งผลกับขอบที่ตัด PNG ด้วย PixiJS จริง
- เลือกแท็บย่อย **ซ้อนภาพ / Depth** เพื่อกำหนด Draw Order ของแต่ละเฟรมเอง สั่ง **อยู่หลังลำตัว/กระโปรง** หรือ **อยู่หน้าลำตัว/กระโปรง** ได้ทันที และสั่งคัดลอกลำดับชั้นไปเฟรมถัดไปหรือทั้งชุดได้โดยยืนยันก่อนเขียนทับ
- `cutout_layers.json` ที่ดาวน์โหลดมี `mask_type`, `mask_polygon_normalized_1000` และ `draw_order_per_frame` เพื่อใช้อ้างอิงต่อ; ขยับ Mask ระหว่างเปิด PixiJS Preview จะอัปเดตภาพแบบหน่วงสั้น ๆ เพื่อลดการสร้าง Mesh ใหม่ซ้ำถี่ขณะลาก

**ข้อจำกัดสำคัญ:** แม้ Polygon ช่วยหลีกเลี่ยงพิกเซลจากอวัยวะที่ติดกัน แต่ **PNG แบนภาพเดียวไม่สามารถสร้างพิกเซลของส่วนที่ถูกบังอยู่เดิม** เช่น ด้านหลังมือหรือด้านในกระโปรงได้ เมื่อขยับมาก ๆ อาจยังเห็นช่องว่าง จำเป็นต้องวาดเติม Layer แยกเองหรือใช้วิธีสร้างภาพเพิ่มเติม; นี่ยังเป็น PixiJS Cutout Prototype ไม่ใช่โปรเจกต์ Spine เต็มระบบ ดูรายละเอียด `UPDATE_v0.8.0.md`

## ใหม่ v0.7 — Mask ที่มองเห็นได้ + Export Center ฝั่งซ้าย

- เปิดโหมด **Rig & Motion** แล้วดูเส้นขอบ **Cutout Mask สีเขียวบนภาพจริง** ได้ทันที เส้นนี้คำนวณจากขอบเขตเดียวกับที่ใช้ตัด PNG ไม่ใช่กรอบสาธิตที่ไม่ตรงการตัดจริง เปิดตัวเลือกแสดงทั้ง 12 Mask พร้อมกันเพื่อดูบริเวณที่ทับกันได้
- ใช้แถบเลื่อนปรับความกว้างรายชิ้น 30–250% พร้อมค่ารัศมีจริงหน่วยพิกเซล; กด **คัดลอกค่าไปอีกข้าง** หรือเปิด **ปรับชิ้นซ้าย–ขวาพร้อมกัน** เพื่อแก้คู่สมมาตร; มีสไลเดอร์ **ปรับความกว้างทุกชิ้น** ในครั้งเดียว
- ลากจุด **START / END** บน Canvas เพื่อย้ายจุดปลายของ Capsule Mask ตามที่ต้องการโดยไม่เปลี่ยนตำแหน่งโบน ใช้ได้ทั้งตอนดู Master และตอนเปิด PixiJS Preview (ภาพ Preview ต้องสร้างชิ้น Cutout ใหม่เมื่อแก้ขอบ)
- ฝั่งซ้ายมี **Export Center** รวมไฟล์ ZIP ทั้ง Bone Guides / Cutout Layers, ภาพรวม, Prompts และ JSON แยกเป็นเมนูพับเก็บ; ฝั่งขวาเป็นพื้นที่ตั้งค่า Motion/Mask และ Draw Order โดยพับหัวข้อที่ใช้น้อยลงได้
- ขอบเขต Mask ที่ปรับเองและความกว้างถูกส่งเข้า Cutout ZIP, PixiJS Preview และ JSON (`cutout_mask_endpoints`, `cutout_width_percent`) เหมือนกัน

**ข้อจำกัด:** ปัจจุบัน Mask เป็นทรงแคปซูลตามโบน (ขยับปลายและปรับความกว้างได้) ยังไม่ใช่ Polygon/Bezier ที่วาดอิสระ, ไม่ใช่ Spine เต็มรูปแบบ และยังไม่สามารถกู้พิกเซลที่ถูกส่วนอื่นบังอยู่จาก PNG แบนเพียงภาพเดียวได้ เมื่อดัดอาจยังเห็นผิวขาดหรือภาพซ้ำ ตรงนี้ต้องวาดเติมหรือเตรียม Layer ต้นฉบับแยกก่อนใช้งานจริง อ่านวิธีอัปเดตใน `UPDATE_v0.7.0.md`

- ถ้าต้องการวางใน ChatGPT แบบเร็ว กด **Copy Master + ทุก Guide เป็นภาพเดียว** แล้ว `Ctrl+V` วางภาพ Contact Sheet ครั้งเดียว จากนั้นกด **Copy Prompt รวมทุกเฟรม** วางข้อความ (ผู้ใช้ยังต้องส่งเอง); วิธีแบบ ZIP ช่วยเก็บแยกเฟรมพร้อมสำหรับแก้ละเอียดในภายหลัง
- เปิด **แสดงภาพที่ Cutout / Deform ด้วย PixiJS**: เว็บทดลองตัดเนื้อภาพจาก PNG ต้นฉบับเป็น 12 ชิ้นตามแนวโบน ใช้ PixiJS `MeshSimple` ดัด Vertex ตามจุดข้อต่อ และเรียง `zIndex` หน้า/หลังตามมุมที่เลือก
- เลือกชิ้น Cutout ปรับ **ความกว้าง Mask 30–250%** และสั่งหน้า/หลังทีละชั้นเฉพาะเฟรม แล้วดาวน์โหลด **Cutout Layers + Render PNG ทุกเฟรม (ZIP)** ได้โดยไม่ใช้ AI
- การดัดภาพแบนแบบนี้เป็น *prototype* เท่านั้น เพราะพิกเซลที่เคยถูกบังอยู่ภายในเสื้อ/ขาไม่มีในภาพ เมื่อดัดจะมีรอยต่อ ภาพซ้ำ หรือช่องว่างที่ต้องวาด/เติมสีด้วยมือหรือเตรียม Layer จริงก่อนใช้ในเกม
- การเปลี่ยน Direction เปลี่ยนโครงและ Draw Order แต่ **ไม่ได้แปลงมุมกล้องของรูป Front ให้เป็นภาพด้านข้างจริง**; สำหรับ Sprite 8 ทิศควรใช้ภาพ Master ของทิศนั้น ๆ แยกกัน

อ่านรายละเอียดไฟล์ที่เพิ่มและขั้นตอนลงทับเดิมได้ใน `UPDATE_v0.6.0.md`

## โหมด Workspace (v0.6)

เมื่อนำเข้าภาพ Master หนึ่งครั้ง รูปเดียวกันจะใช้ร่วมกันได้ครบทุกโหมด ผ่านเมนูขนาดใหญ่ใต้แถบหัวเว็บ:

| โหมด | ใช้ทำอะไร | ไม่ได้ทำอะไร |
|---|---|---|
| **สี / Tag** | Inspect สี/วัสดุ/เทคนิคจาก MD และแก้ชื่อ Tag, Region, Palette | ไม่ได้ดูดสีหรือแบ่ง Layer อัตโนมัติจากกรอบ Region |
| **Shape** | วาดรูปทรงเป้าหมาย Mirror แขน/ขา หาพื้นที่สีคร่าว ๆ และส่ง Shape Guide ให้ AI | ไม่ได้เปลี่ยนพิกเซล PNG ในเว็บ |
| **AI Edit** | เตรียม Prompt + Mask สำหรับแก้ส่วนที่เลือกกับ AI ภายนอก | ไม่ได้เรียก API หรือ Inject เข้าแท็บ ChatGPT |
| **Rig & Motion** | วางโครง 19 จุด จัดท่า Idle/Walk/Run/Custom 1–16 เฟรม จัดหน้า/หลัง ทดสอบ PixiJS Mesh Cutout และ Export ZIP ครบทุกเฟรม | ไม่สามารถเติมพิกเซลที่ถูกบังใน PNG ต้นฉบับหรือเปลี่ยนมุมตัวละครจริงโดยอัตโนมัติ |
| **MD / Data** | อธิบาย JSON/MD เช็ก Mapping และ Export | ไม่ใช่ที่วาด/เปลี่ยนสีของพิกเซล |

### สี / Tag — เพิ่ม เปลี่ยน ลบ และดูดสี

1. นำเข้ารูป + MD ที่ขนาดตรงกัน หรือเปิด Demo
2. เลือก Tag ทางซ้าย แล้วกด **Tag & Palette** ในแถบด้านขวา
3. ใน **Palette Edit** สามารถเลือกสีด้วย Color Picker, ตั้งชื่อสี, แก้ Role (`base` / `shadow` / `highlight`), กด **ลบ** รายการสี หรือ **ดูดสี** จากพิกเซลบนภาพโดยคลิกจุดที่ต้องการ
4. กด **Export MD** เพื่อบันทึกข้อมูล Tag และ Palette ที่ปรับ

`Tag ID` เป็นรหัสคงที่เพื่ออ้างอิงชิ้นส่วนหนึ่ง ๆ; `Region` เป็นพิกัด Polygon สำหรับเลือกพื้นที่และบอก AI ว่าเกี่ยวข้องกับส่วนใด; `z_index` เป็นลำดับแสดงขอบเขตที่ซ้อนกัน ไม่ใช่การย้ายชิ้นส่วนใน PNG. การแก้ Palette เปลี่ยน **ข้อมูลอ้างอิง** ไม่ได้ Recolor รูปต้นฉบับ

### Shape — Mirror และ Magic Wand

- **วาดพื้นที่เอง:** คลิกบน Canvas อย่างน้อย 3 จุด แล้วกดจบรูปทรง จากนั้นลากจุดสีเหลือง/สไลเดอร์ปรับได้
- **Magic Wand:** กดจับขอบสีอัตโนมัติ แล้วคลิกพื้นที่สีบนตัวละคร ระบบคัดพื้นที่สีต่อเนื่องที่ใกล้เคียงพิกเซลที่คลิก และประมาณขอบด้วย Convex Hull (ล้อมเป็นรูปนูน) ซึ่งต้องตรวจ/ลากแก้เอง ห้ามถือว่า AI รู้ว่าเป็นแขน ขา หรือตัดชิ้นภาพได้ถูกต้อง
- **Mirror:** เปิดเฉพาะส่วนที่สมมาตร เช่นแขน/ขา/รองเท้า ปรับแกนกลาง X ได้; อย่าเปิดกับทรงผมหรือเครื่องแต่งกายที่ไม่สมมาตร
- **ส่งออก:** Copy รูปต้นฉบับ → วางใน ChatGPT → Copy Shape Guide → วางเพิ่ม → Copy Prompt → วางข้อความแล้วส่ง

### Rig & Motion — 8 Directions / 1–16 Frames / PixiJS Cutout

1. เปิดภาพ Master ที่ต้องการใช้เป็นต้นแบบ (หนึ่งภาพอาจเป็น Front, West หรือทิศใด ๆ)
2. เข้า **Rig & Motion** เลือกทิศ `S / SW / W / NW / N / NE / E / SE`
3. กด **วางโบนตามขนาดรูป** เพื่อเริ่มจากสัดส่วนตัวละครบนพื้นโปร่งใส แล้วลากจุดหัว ไหล่ ข้อศอก ข้อมือ สะโพก เข่า ข้อเท้าให้ถูกจริง; ขั้นนี้เป็น *การประมาณสัดส่วน* ไม่ใช่ AI Pose Detection
4. เลือก Motion เช่น `Idle` 4 เฟรม หรือ `Walk` 8 เฟรม (สามารถปรับเป็น 1–16) แล้วกด **สร้างท่า** เพื่อคำนวณการขยับเริ่มต้น ก่อนแก้โบนทีละเฟรมตามต้องการ; เมื่อลากข้อเท้าหรือข้อมือ ระบบช่วยขยับเข่า/ศอกด้วย IK 2 ท่อน
5. ตั้ง **Depth / Near Side** รายเฟรมว่า ซ้ายตัวละคร หรือขวาตัวละครควรอยู่ใกล้กล้องและทับส่วนไกลกว่า; ค่า Auto ตามมุมเป็นค่าเริ่มต้น ไม่ใช่กฎตายตัวเมื่อแขนหรือขาไขว้กัน
6. กด **รวม Bone Guide + Prompt ทุกเฟรม (ZIP)** เพื่อดาวน์โหลดทั้งหมดพร้อมกัน หรือกด Copy Contact Sheet + Copy Prompt รวมเพื่อส่ง ChatGPT เพียงครั้งเดียว
7. เปิด **PixiJS Cutout Preview** ถ้าต้องการดูพิกเซลในภาพ Master ถูกตัดและดัดตาม Bone จริง ปรับขอบ Mask/Draw Order แล้ว export Cutout Layers และภาพ PNG เฟรมที่ระบบ Render

**ข้อจำกัดที่สำคัญ:** ตอนนี้ Cutout Preview ดัดพิกเซลจริงด้วย PixiJS ได้ในระดับ *Prototype* โดยตัดชิ้นแบบประมาณ แต่ภาพ PNG แบนไม่มีสิ่งที่ถูกบังอยู่เดิม เมื่อลากแขน/ขาจะเกิดช่องว่างหรือรอยต่อได้ ต้องแก้ Mask/ภาพต้นทางหรือเตรียมภาพแยก Layer อย่างจริงจังก่อนผลิต Sprite เกม; และโหมดนี้ไม่ได้เปลี่ยนมุมกล้องของภาพต้นฉบับให้เป็นอีกทิศด้วย

## เริ่มทดลอง

1. เปิดแอปจะพบ **หน้าแรก (Home)** พร้อมภาพ Novice Male/Female สำหรับโชว์เท่านั้น **ยังไม่โหลดภาพใดเข้าพื้นที่ทำงาน**
2. กดเมนู **Character Design** หรือ **Template Guide** เพื่อเปิด `#guide` ซึ่งมีขั้นตอนเริ่มต้นสำหรับคนที่ยังไม่มีรูปเลย
3. **ขั้นที่ 01 — สร้างรูป Master:** กรอกลักษณะตัวละครในช่อง Concept แล้วกด **คัดลอก Prompt ทั้งหมด** ไปวางที่ AI สร้างภาพ จากนั้นบันทึกภาพตัวละคร (แนะนำ PNG พื้นหลังโปร่งใส) หากมีรูปอยู่แล้วข้ามได้
4. **ขั้นที่ 02 — ดาวน์โหลด AI Template:** กดดาวน์โหลด `AI_CHARACTER_MAPPING_TEMPLATE.md` ซึ่งอธิบายกติกาการแบ่งชิ้นส่วนและรูปแบบข้อมูล
5. **ขั้นที่ 03 — สั่ง AI วิเคราะห์:** แนบ **รูป Master + Template .md สองไฟล์พร้อมกัน** ใน AI ที่รองรับไฟล์แนบ วางคำสั่งที่กดคัดลอกจากหน้า Guide และบันทึกผลลัพธ์เป็น `.md` เช่น `my_character_map.md`
6. **ขั้นที่ 04 — เข้าสู่ Workspace:** กด **นำเข้ารูป** เพื่อเลือกรูปเดิม แล้วกด **นำเข้า MD** เพื่อเลือกไฟล์ที่ AI กรอกให้; ถ้าแผนที่ถูกต้องจะเห็น Part/Region บนรูป (หรือเปิด Example ที่มีตัวอย่าง 19 ส่วน)
7. **Zoom:** คลิกภาพ **หนึ่งครั้งเพื่อ Focus** แล้วหมุนล้อเมาส์เพื่อซูมตามจุดที่เมาส์ชี้ ช่วง **25%–1,000%**; ใช้ปุ่ม `−`, `+` และ Reset 100% ได้เสมอ
8. **Pan:** กด **ล้อเมาส์กลางค้างไว้** แล้วลากซ้าย/ขวา/ขึ้น/ลงเพื่อเลื่อนดูภาพ ใช้ได้แม้คลิกตรง Polygon และเมื่อภาพขนาดพอดี Canvas (พื้นที่เลื่อนมีขอบรอบภาพให้ด้วย)
9. ชี้/คลิกส่วนบนรูปเพื่อดู Material, Hex Palette, Layer, เทคนิควาด; Shift+Click หรือกดเครื่องหมายหน้า Part เพื่อเลือกหลายชิ้น
10. กด **AI Edit** ใส่คำสั่ง เช่น `เปลี่ยนบูตหนังทั้งสองเป็นรองเท้าเกราะคริสตัลฟ้าและเงิน` แล้วคัดลอก Prompt หรือ Export Edit JSON/Mask PNG สำหรับ AI ภายนอก
11. ถ้า Polygon ยังไม่ตรง ใช้แท็บ **Tag & Region** ปรับจุดหรือวาดขอบเขตใหม่ แล้ว Export MD เก็บคู่กับรูปต้นฉบับ
12. **Shape Guide (ใหม่ v0.4):** เมื่อมีภาพ Master แล้ว กดแท็บ **Shape** → เลือก Region จาก Tag (ถ้า MD ตรงภาพ) หรือ **วาดพื้นที่เอง** โดยไม่จำเป็นต้องมี MD → คลิก 3 จุดขึ้นไปบน Canvas → ปรับรูปทรงเป้าหมายด้วยจุดสีเหลืองหรือสไลเดอร์ความกว้าง/สูง/องศา/เลื่อน → ระบุคำขอแก้รูปทรง
13. สำหรับ ChatGPT บนเว็บ กด **Copy รูปต้นฉบับ** แล้วสลับแท็บไป Ctrl+V วางในกล่องแชต → กลับมากด **Copy รูป Shape Guide** แล้วไป Ctrl+V วางเพิ่ม → กลับมากด **Copy Prompt แก้รูปทรง** แล้ววางข้อความ → กดส่ง **ครั้งเดียวเมื่อแนบครบ 2 รูป + คำสั่ง** (Clipboard เก็บรายการล่าสุดเท่านั้น)

**Keyboard shortcuts เมื่อ Focus อยู่ใน Canvas:** `+` ขยาย, `-` ย่อ, `0` กลับ 100%; **กดล้อเมาส์กลางค้างแล้วลาก** เพื่อ Pan. ปุ่มซูมไม่ต้อง Focus ก่อนใช้งาน

### JSON ต่างจาก MD อย่างไร?

- **PNG**: รูปตัวละครจริงที่มองเห็น
- **MD (Markdown)**: ไฟล์คำบรรยายสำหรับคนอ่าน พร้อมบล็อก `character-map` ที่ AI กรอกให้
- **JSON**: ข้อมูลในบล็อก `character-map` ที่อยู่ **ภายใน MD** (เช่น ชื่อ Part, สี HEX, และ Polygon); โปรแกรมนำไปอ่านและวาดกรอบซ้อนบนภาพ

ผู้ใช้ทั่วไป **ไม่ต้องใช้ปุ่มนำเข้า JSON** ถ้า AI ส่งไฟล์ MD ที่ถูกต้องแล้ว ปุ่ม JSON มีไว้รองรับข้อมูลแบบแยกไฟล์หรือใช้ในโค้ดในอนาคต

## นำเข้าไฟล์จริง

- กด **นำเข้ารูป** เพื่อเลือก PNG/JPG/WebP; เมื่อนำเข้าภาพใหม่ Annotation เก่าจะถูกล้างเพื่อป้องกัน Tag ผิดรูป
- กด **นำเข้า MD** เลือกเอกสารที่มี fenced block แบบ ` ```character-map `; ระบบตรวจ schema, `part.id`, สี, และ polygon
- **ป้องกัน MD คนละภาพ (v0.4):** หากขนาด `image.width/height` ใน MD ไม่ตรงรูปปัจจุบัน ระบบบล็อกการนำ Polygon มาแสดงและมีปุ่มนำเข้ารูปต้นทางที่ถูกต้อง หรือ Copy Prompt ขอ AI สร้าง MD ใหม่จากรูปนี้ หากขนาดตรงแต่ชื่อไฟล์ไม่ตรง หรือ MD มีหลายเฟรม/จำนวน Tags ผิดปกติ ระบบซ่อน Region จนกว่าจะกดยืนยันหลังตรวจด้วยตา
- **ตรวจพิกัดบนพื้นโปร่งใส:** ระบบสุ่มจุดใน Polygon มาตรวจว่าไปทับพื้นที่โปร่งใสของ PNG มากผิดปกติหรือไม่ ถ้าผิดจำนวนมากจะซ่อน Region และแจ้งเตือน วิธีนี้เป็นเพียงตัวช่วยเตือน ไม่ใช่ AI Segmentation และอาจพลาดเมื่อ PNG มีพื้นหลังทึบ
- ถ้า MD เดิมเป็นข้อความทั่วไป **ไม่มีพิกัด Region** แอปจะยังเก็บเอกสารให้ดู แต่ไม่สามารถรู้ตำแหน่งแม่นยำได้โดยอัตโนมัติ ต้องใช้ AI Template ขอให้ AI กรอก `character-map` แล้วนำเข้าใหม่ หรือเพิ่ม Tag ด้วยตัวเอง
- ระบบใช้ **normalized_1000** (พิกัดภาพช่วง 0–1000 แยกแกน X/Y) เพื่อไม่ต้องสร้างพิกัดใหม่ตามขนาดจอ

## ขอบเขตและความจริงที่ควรรู้

- Polygon ที่แนบกับตัวอย่าง Novice Female เป็นการ **วาดประมาณตามภาพ** เพื่อสาธิต UI ไม่ใช่ Mask แบบ pixel-perfect
- ตัวอย่างสีเป็นค่าประมาณที่ทำขึ้นสำหรับระบบ ไม่ใช่การคัดสีทุกพิกเซลของภาพแบบ forensic
- PNG ที่นำเข้าเป็นภาพแบน ไม่ใช่ layer ของ Krita; Part บนเว็บเป็น Semantic Overlay
- แอปนี้ **ยังไม่เรียก AI image-edit API จริง** (ไม่มี Cloudflare Workers AI integration); ทำ Prompt + Edit JSON + Mask เพื่อส่งไปใช้เองก่อน
- **Shape Guide เป็นการทำภาพประกอบคำสั่ง ไม่ใช่การบิด Mesh/Pixels ในแอป:** ภาพต้นฉบับไม่ถูกแก้ด้วยสไลเดอร์; AI ภายนอกจะนำภาพต้นฉบับและภาพเส้นกำกับไปวาดผลลัพธ์ ผู้ใช้ต้องตรวจความต่อเนื่องของแขนขาและสีด้วยตา
- **การส่งเข้า ChatGPT ไม่ใช่การ Inject แท็บเว็บ:** ปุ่มเปิดแท็บและ Copy ช่วยเตรียมให้วาง Ctrl+V ด้วยตัวเองเท่านั้น; ไม่สามารถสั่งการแท็บ ChatGPT ที่เปิดอยู่ หรือรับรูปที่ AI สร้างกลับอัตโนมัติ
- การนำภาพใหม่มาเปรียบเทียบเป็น Preview ในหน่วยความจำของแท็บ; ต้องเก็บ/Export ไฟล์เอง ไม่มี database และไม่แก้ภาพต้นฉบับอัตโนมัติ
- มีการตรวจข้อมูลเบื้องต้นและแก้ polygon เองได้ แต่ยังไม่มี segmentation AI อัตโนมัติหรือ polygon holes
- โปรดตรวจ L/R: ด้านซ้ายของตัวละครหมายถึงซ้ายตามกายวิภาค **ไม่ใช่ซ้ายของคนมองภาพ**
